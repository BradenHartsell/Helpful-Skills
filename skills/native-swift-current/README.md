# Kotlin Native and Swift Interoperability

**Skill ID:** `native-swift-current`

**Compiled:** 2026-07-28

Design, migrate, debug, and validate Kotlin/Native Apple frameworks,
Objective-C export, Swift export, Swift Package Manager integration, coroutine
and Flow bridging, exception boundaries, memory ownership, and packaging.

Use it when Kotlin APIs must be consumed safely from Swift or Objective-C, or
when iOS and macOS interoperability becomes real.

Start with [`kotlin-current`](../kotlin-current/) to establish Kotlin, Apple
target, Xcode, and export-mode facts. The references keep Objective-C export,
Swift export, async bridging, memory, and packaging contracts distinct.

The audit script is optional. Apple readiness requires a compiled consumer,
cancellation, exception, deallocation, executor, and release-package proof.
